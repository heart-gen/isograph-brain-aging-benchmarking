# NONO perturbation target panel

Generated by `isograph_benchmark.real_data.rbp_target_panel` (scope=mature, background=composition, module q <= 0.05, max 3 genes per module, rank_by=adjusted).

## How the list was derived

A gene is **eligible** only if both layers agree: its IsoGraph switch pair changes NONO motif presence (`rbp_switch_calls.switched`), *and* its module is an independently enriched NONO regulon (`rbp_regulon.q <= 0.05`) that is itself phenotype-associated. Eligible genes are ranked by the covariate-adjusted GLM: genes whose best module has an adjusted odds ratio above 1 first, then by the lower bound of that module's adjusted 95% CI, then by recurrence across brain regions, then by the number of regions where the module's regulon call is eCLIP-binding-supported, then by unadjusted module q, then by the gene's own switch-driver strength (max |switch_r|), then alphabetically.

Eligibility stays on the **hypergeometric** q because no NONO module reaches adjusted q <= 0.05 (best adjusted q = 0.000); gating on the adjusted arm would leave no panel at all. The adjusted arm is used to *order* the candidates and to demote modules it contradicts.

Candidate universe: **670 eligible genes** (127 more are switched-and-enriched but never in a phenotype-associated module); 19 recur in >1 region; 670 have eCLIP support in >=1 region.

## Caveats

- **No NONO module survives opportunity adjustment at FDR.** The length/GC/UTR-adjusted GLM (`qvalue_glm`) reaches q <= 0.05 for 361/670 of these genes' best modules (best adjusted q = 0.000); 443 best modules have an adjusted odds ratio above 1 and 443 have an adjusted CI that excludes 1 before multiplicity. The module-level claim is therefore 'enriched relative to the switch-gene pool', not 'enriched after full opportunity adjustment'. This is a prioritized hypothesis set for a perturbation experiment, and must not be described as an FDR-significant regulon.
- Motif gain/loss is sequence-predicted. eCLIP support (`eCLIP` column) is module-level and isoform-preferential, not per-target binding evidence.
- Genes whose region contributed via the fallback full module-gene pool (`pheno_module == False`) come from a module with no FDR-significant phenotype association in that region; `n_regions_pheno_module` records how many regions carry the stronger pool.
- Recurrence is module-driven: the most widely recurrent NONO regulon supplies far more high-ranked genes than the module cap admits. Check the *Modules sampled* table before assuming the panel spans distinct biology, and check that the sampled modules' cell-type biology matches the model system the panel will be tested in (an immune/inflammatory module is not testable in a purely neuronal culture).
- Freeze this ranking **before** any collaborator expression (TPM) screen. Use the screen only to decide which prespecified targets are testable in their cell model; selecting targets because they happen to be well expressed is a post-hoc step.
