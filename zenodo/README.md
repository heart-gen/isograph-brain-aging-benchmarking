# Zenodo data bundle

The GitHub repository (with Git LFS) carries the **lean result artifacts** needed to
reproduce the figures and statistics: module assignments, age/diagnosis associations,
GO/network enrichment, xQTL anchoring, stability summaries, GWAS results, and the
per-module interpretation tables.

The **heavy regenerable artifacts** are too large for the repo and are distributed
via Zenodo instead. They are git-ignored (see `.gitignore`) and listed in
`MANIFEST.tsv`:

| artifact | what it is | regenerated by |
| --- | --- | --- |
| `feature_scores.parquet` | per-sample switch/abundance feature matrix | `run_models.py` (IsoGraph fit) |
| `feature_reconstruction.parquet` | VAE feature reconstruction | `run_models.py` |
| `high_vs_low_table.parquet` | per-module high-vs-low expression interpretation | `interpret_modules.py` |
| `edges.parquet` | IsoGraph network edge lists | `run_models.py` |

All four are deterministic outputs of the committed pipeline at canonical Leiden
resolution 5.0; the lean committed artifacts (`modules.parquet`, `node_diagnostics.parquet`,
etc.) are derived from them.

## Staging for upload

```
scripts/stage_zenodo_bundle.sh --checksums   # writes MANIFEST.tsv (path, bytes, sha256)
scripts/stage_zenodo_bundle.sh --tar         # also build the upload tarball
```
